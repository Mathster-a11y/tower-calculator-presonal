# Torre 3D CIRSOC

Aplicación web didáctica para diseñar y calcular torres (edificios en altura, miradores escultóricos y torres reticuladas) con geometría libre, un motor FEM verificado analíticamente (doble integración y viga de Timoshenko) y sincronización bidireccional con Google Sheets. La única referencia normativa son los reglamentos CIRSOC.

## Estado

Fase 0: propuesta e investigación. Ver [`docs/propuesta/index.html`](docs/propuesta/index.html), que incluye:

- el mapa normativo CIRSOC → módulos,
- la investigación de repositorios abiertos (con licencias y qué se toma de cada uno),
- capturas de referentes (con atribución),
- la demo 3D y las maquetas de la propuesta,
- la arquitectura, el diseño de la sincronización con Sheets y el plan por fases,
- las preguntas abiertas.
